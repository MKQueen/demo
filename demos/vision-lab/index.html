    OPERATING NOTES

    怎么玩这个 Demo

    1. 选输入：摄像头实时流、上传视频文件，或上传图片（也可以用两张示例图快速体验）。
    2. 看标注：检测框颜色对应类别；右侧列表按置信度排序，点击条目可以高亮对应目标。
    3. 调参数：置信度阈值越高越严格；帧率受设备性能影响，CPU 推理通常 8–15 FPS。
    4. AI 解读（可选）：本地运行 npm run serve 并配置模型 Key 后可用。「标签解读」只把识别标签发给模型；「AI 精读」会把当前帧压缩后上传，换来更准的物体清单与场景描述。静态部署时这两个按钮会显示未连接。
    5. 检测模型：「高精度」用 EfficientDet-Lite2（448 输入，小目标更准）；「快速」用 Lite0（320 输入，更省算力）。COCO 80 类之外、遮挡严重或过小的物体仍可能漏检。
    6. 跟踪与事件：同一目标跨帧会保持稳定 #ID（IoU 匹配 + 框平滑），右侧记录进入/离开画面与停留时长；这不是生产级 MOT，目标交叉或快速运动时 ID 可能切换。

    模型：MediaPipe EfficientDet-Lite0 / Lite2（COCO 80 类），WASM + Worker 本地推理；摄像头画面不会离开你的电脑（AI 精读除外，需你主动点击并上传到本地模型网关）。 示例图片来自 Pexels（Pexels License，免费使用）。
