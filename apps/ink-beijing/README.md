# 水墨北京 · 一纸山河

用 Three.js 在浏览器里「画」一座北京。不依赖外部图片与现成模型——宫城、中轴、九门、胡同、
天坛、白塔、颐和园、长城、卢沟桥，全部由代码在运行时生成，最后用一层自定义后期把所有几何压成
宣纸上的墨色。

> 灵感与美术方向参考自 [gamemcu.com/hz](https://gamemcu.com/hz/)（水墨杭州），
> 但内容、几何、着色与交互全部为本项目独立实现。

## 本次升级

- 开场直接显示从景山北侧向南望宫城的实景，题字叠在画面上；入京后缓慢推进，保留全城总览。
- 城外沿九条驿路生成成组院落、支路、连片田畴和林带，河岸柳树串起西郊园林；共享水域、山地、城界和地标排除规则。
- 田畴使用程序化图集与独立墨色遮罩，田垄保留，田面不再被描成空心方框。
- 修复旧版远郊村舍在几何合并后追加、没有进入最终场景的问题；村舍统一在生成完成后合批。
- 后期读取不透明材质 alpha 中的笔墨权重：灰瓦与墙面淡化，宫墙金顶保留轮廓；近远景的墨线分层，纸纹停止漂移。
- 新增「宫阙远眺 / 城外烟树 / 京城总览」三个入口和「藏签」，桌面最多七个标签、窄屏最多四个；支持减少动效偏好。
- 运行时可从画布的 `data-landscape` 属性查看实际生成的村落、房屋、田块和树木数量。原有性能数据为升级前记录，不能代表新版。

## 内容

- **中轴线**：永定门 → 正阳门 → 天安门 → 午门 → 太和殿 → 神武门 → 景山 → 钟鼓楼，一线上排开。
- **现代北京**：国贸 CBD（中国尊、国贸三期、央视大楼、银泰、京广、建外 SOHO 与一片配角塔楼）、
  鸟巢、水立方、奥林匹克塔、国家大剧院——古都在纸上一路往东长出了另一座城。
- **城市规划**：皇城（天安门/地安门/东安门/西安门/长安左右门）围着宫城与三海，两侧太庙、社稷坛
  （三层方台五色土）；内城九门、外城完整七门与四面城墙、角楼、护城河；日坛/月坛/地坛/先农坛四郊坛庙；
  东四/西四/东单/西单/前门牌楼，前门大街、鼓楼、大栅栏的商铺街；玉河故道从什刹海引到东便门。
- **烟火气**：城里 200 个院落屋顶会一缕缕冒出淡墨炊烟，暮色和雪天更明显。
- **城郊**：成排的果园/林带、细墨线的田垄、驿路行道树与村舍——全部是实物，没有会被墨线描边的色块。
- **紫禁城**：三台白基上的重檐庑殿太和殿、中和殿、保和殿、乾清宫、午门、神武门、四角角楼、金水桥。
- **内城九门**：内城城墙、垛口、角台与九座城门楼；外城城墙与永定门。
- **胡同**：东四、西四、南锣鼓巷、前门一带的程序化四合院，用 InstancedMesh 生成上千座灰瓦院落，
  形成疏密有致的胡同肌理。
- **山水**：西山、燕山、万寿山、昆明湖、北海、中南海、什刹海、福海、护城河、长河、通惠河与永定河；
  远山用多层淡墨 + 雾带化成纸上的剪影，湖面有细密线描波纹、缓慢涟漪、小舟与假倒影。
- **地标**：天坛（三重圆顶祈年殿 + 圜丘坛）、北海白塔与琼华岛、颐和园佛香阁与十七孔桥、
  圆明园（福海 + 大水法残柱）、玉泉山塔、香山琉璃塔、八达岭长城、卢沟桥与宛平城。
- **氛围**：晨光 / 暮色两套天色、低悬的日轮、盘旋的鸽群、岸边的垂柳与杏花、风里轻摆的树、
  湖上缓慢移动的小舟、漂移的雾带与山顶云气、院里升起的炊烟。
- **雪中北京**：点「雪霁」整城落雪——灰瓦与纸面覆上冷白，朱墙金顶反而更跳，水面成冰，
  空中有细雪飘落；再点「晨暮」是雪后天色，暮色在雪天会转成冷蓝。

## 交互

| 操作 | 效果 |
| --- | --- |
| 拖拽 | 绕目标旋转视角 |
| 滚轮 / 双指捏合 | 推近拉远 |
| 右键拖拽 / 双指拖动 | 平移观察中心 |
| 点击朱印地标 | 打开纸卡，读一段这座城的注脚 |
| 纸卡「去看看」 | 相机缓动到该地标近景 |
| 底部「地图中心」 | 回到全城机位 |
| 底部「暮色 / 晨光」 | 切换天色（灯光、雾、纸色一起过渡） |
| 底部「墨色」滑杆 | 调节后期墨线 / 墨色浓淡 |
| 键盘 `R` / 方向键 | 回正 / 微调视角 |

## 技术要点

- **1 世界单位 = 50 米**，垂直方向 ×1.8 夸张（`src/lib/units.js`），让鸟瞰时的屋顶有体量。
- **中国屋顶生成器**（`src/lib/roof.js`）：把「举折 / 起翘 / 出翘」写成参数化曲面，
  庑殿、硬山、攒尖、圆形攒尖四种型制由同一套参数描述；正脊、垂脊、檐口板自动生成。
- **水墨后期**（`src/lib/ink.js`）：场景先渲进带深度纹理的 HDR 目标，再用全屏 shader 做
  深度 + 亮度双 Sobel 让建筑自己「长出」墨线，然后降饱和、叠纸纹、压角。
- **程序化纹理**（`src/lib/textures.js`）：宣纸、墨晕、线描水波、雾、树影、光晕全部由 Canvas 生成。
- **程序化树**（`src/lib/flora.js`）：参考 procedural-tree 的做法重写——先用噪声/向光性/重力
  「长」出递归骨架并扫成管道几何（松直干分层、槐多分叉、柳垂丝、花树细枝），枝梢挂 Canvas 现画的
  水墨叶团，并用**球形法线**让同一丛叶子明暗连续；风在顶点着色器里吹，整片林子会轻轻晃动。
  每（种×变体）枝条与叶团各 1 个 InstancedMesh，四千多棵树只有 23 个 draw call。
- **总平面稿**（`src/layout.js`）：中轴节点、城墙、湖岸、河道、山形、长城走线、地标锚点全部集中在这一份
  「地理底稿」里，城市 / 地标 / 自然三个模块只负责把它画出来。
- 全场景约 **109.1 万三角形 / 144 draw call**（其中 5280 棵树 23 draws / 71 万三角形），
  此为升级前记录；新版增加了近郊院落与林地，需在目标设备重新测量帧率。

## 反复看的两处

- **古今同框**：默认机位右侧是国贸 CBD，正前方是中轴宫阙，北面是奥林匹克塔与山影；点地标的朱印可飞近看。

## 运行

```bash
cd apps/ink-beijing
npm install
npm run dev      # http://localhost:5173
npm run build    # 产物在 dist/，可直接放进任意静态托管子目录
```

作为 DEMO LAB 合集的一部分，也可以回到仓库根目录执行 `npm run build`，
它会被构建并拼进 `site/demos/ink-beijing/`。

```

└─ world/            场景模块
   ├─ index.js       拼装
   ├─ terrain.js     纸面与墨晕
   ├─ water.js       湖河水面与水岸
   ├─ city.js        中轴线、宫城、城墙、胡同
   ├─ landmarks.js   天坛、北海、颐和园、长城、卢沟桥

```

## 已知取舍

- 这是一张**画**，不是 GIS：地理比例、建筑尺度为画面服务做了取舍（尤其是高度与距离）。
- 中轴线长度按真实 7.8 km 压缩到画布尺度，地名与相对方位忠实，绝对经纬度不忠实。
- 需要 WebGL2；移动端会自动降低像素比与植被密度。
