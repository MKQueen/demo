# V9：白天城市与战斗可读性

本轮继续使用现有机甲、怪兽，改善环境资源、材质、镜头和接触特效。没有新增独立机甲模型。

- 公开免费资产：Poly Haven 的 Tree Small 02、Kloppenheim 06 Pure Sky，均为 CC0。来源和派生处理见 CREDITS.md。
- 树木用下载的模型替换球形树冠；焊接、减面和 512px 贴图处理后约 1.14 MB、8692 个三角面。全城使用三个实例化批次。靠近地面的碾压会触发约 1.1 秒的倒伏，空中经过不会触发。
- 新增玻璃幕墙、退台式屋顶、底层玻璃入口、雨棚、立柱；窗格统一尺寸，窗面接受环境光与反射。变体仍接入原有倒塌和遮挡淡出系统。建筑碰撞仍按外包盒近似。
- 使用真实室外 HDR 天空生成反射，调整金属装甲和怪兽皮肤的粗糙度及反射强度；加载失败时保留室内反射作为后备。
- 近战命中改成短促局部闪光、碎屑和尘雾，减少遮住手臂的大光圈、漫画斩线和速度线。近身镜头向侧面移动，保持玩家及怪兽同框。
- 落脚尘雾放在导入模型的脚骨位置，怪兽脚步震动随距离衰减。脚步节奏仍沿用原有步态计时，没有改成完整接触物理。
- 出生裂隙改为固定的焦痕与细碎裂纹，移除旋转橙色圆环和直线放射光条。保留白昼。

验证：15 项单元测试、生产构建通过；visual-v9-smoke、camera-v7-smoke、browser-smoke、contact-combat-smoke 浏览器检查通过。植被检查覆盖三角面预算、空中/地面碾压、渐进倒伏、有限变换矩阵以及重建后的几何资源释放。

实测场景约 75 棵树、约 163 万个渲染三角面（含阴影渲染），全场景约 887 次绘制。植被实例化减少了额外绘制次数，但整个城市仍有很多独立楼体，低配置设备仍可能需要后续 LOD、合批及图形档位优化。没有据此保证 60 FPS。

这仍未解决独立角色资产、完整非人形怪兽动作、多关卡和部位破坏；场景主体仍是程序化建筑。当前目标是让现有战斗画面更协调，不应称为最终写实成品。
