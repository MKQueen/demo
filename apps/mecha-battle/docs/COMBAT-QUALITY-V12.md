# 战斗质量样板 · v12

2026-10-24。本轮继续网页版，集中修改远程规则、喷焰/吐息和接触反馈，不新增机甲、地图或引擎迁移。

## 已实施

### 远程规则

`src/combat/projectileFlight.js` 与 `playerProjectiles.js` 替代原先“插值到目标、到时间扣血”的流程。

- 等离子释放时瞄准当前目标，随后方向固定，速度 115 米/秒、寿命 2.8 秒；目标横移可以躲开。发射前 .32 秒仍有聚能承诺窗口。
- 导弹速度 64 米/秒、寿命 4 秒；前 .12 秒离架，随后最多每秒转向 2.1 弧度，不再任意拐弯或加速到目标。与建筑接触会提前爆炸。
- 每个模拟步沿飞行路径求最早碰撞：地面、未倒塌楼体的扩展盒、角色骨骼胶囊。射线/胶囊交点为解析求解；移动目标使用相对位移，轴旋转做有界细分。
- 命中点与法线用于接触反馈，单发碰撞后立即移除。射空到寿命仅销毁，不产生假伤害、命中音、爆炸或顿帧。
- 不再因为附近有楼就把发射方向偷偷切到楼中心；沿已瞄准方向飞行，楼体仅通过实际碰撞挡弹。显式指定建筑目标的内部接口仍保留。

这仍是简化角色胶囊/楼体盒碰撞，不是模型三角面级弹道或真实装甲弹道模拟。

### 喷气与技能材质

`src/world/flowVFX.js` 提供交叉透明片、四层噪声流动、柔边、扰动、长度渐隐和热区变化。

- 背部/脚底四路喷流替换原来的实心圆锥；机动强度控制喷流长度，保留地面扬尘和原有燃料/飞行逻辑。
- 等离子由带套环的大光球改为小型拉长能量核及短尾；手部蓄力也移除实体圆环。
- 怪兽吐息替换原来的圆柱束与分段柱体；橙色火流采用普通透明混合，减少白色中心和泛光溢出，区别于蓝色机甲喷焰。
- 移除怪兽背部临时八面体发光装饰；嘴部与实际攻击挂点承担蓄力反馈。

这些是本项目编写的着色器，尚未接入第三方高质量爆炸/烟火序列素材，也不是体积光线步进或流体模拟。其目标是先消除明显几何原型感，仍需进一步美术制作和低配帧耗时验证。

### 吐息规则与反馈

- `breathVolume.js` 使用与火流一致的三维轴线与渐扩宽度，检查角色骨骼胶囊；高度影响受伤，不再只看地面矩形。
- 楼体先截断本次火流，再承受伤害；这一口吐息不会在同一帧穿过被它打坏的掩体。渲染长度和伤害末端同步缩短。
- .8 秒持续时间内，后来进入火流仍会被命中；同一次吐息只结算一次直接伤害，独立地面灼烧仍按原规则造成持续伤害。
- 爪击挥空不再生成大斩击贴片、命中火花或震屏，接触由实际扫掠判定触发。重踏移除漫画星爆，保留扬尘与物理碎块。
- 移除游戏调用处的漫画星爆/速度线叠层；旧效果库仍保留供未重制内容回退，光刃等遗留表现尚未全部重制。
- 等离子火花朝接触面外侧散射，冲击环朝向接触法线；普通命中不再持续整屏刷白。
- 近战/弹体命中使用一处撞击声，避免与统一伤害函数重复叠加。没有新增录制音效资源；合成音质量仍需后续替换。
