# 核心战斗复评与首批修正

当前只适合开发测试。现有完成项、自动测试数量和系统数量不能证明达到发行质量。
本次依据 V14 截图、战斗/动画源码与脚本驱动浏览器复测；没有进行真人体感体验测试。

## 查到并修正的问题

- 重拳时长 1.05 秒，在 51% 时输入下一拳，原固定 0.4 秒缓存会早于剩余动作结束而过期。现在仅保留一次输入，从动作 24% 后接收，并保持到剩余动作时间加 0.12 秒。受击、闪避、重开仍清除缓存。
- 原拳击根节点从动作起始线性前移，蓄力像滑步。现在轻拳在 18%—47%、重拳在 30%—56%、刀在 12%—50% 完成平滑进身；未修改攻击总时长或命中窗口。
- 集中进身时原步幅超出支撑腿可达范围。缩短轻拳/刀步幅到 1.6 米、重拳到 2.4 米；脚锁定回归检查最大漂移约 0.172 米。这仍不是专业制作的整套进身动画。
- 怪兽原攻击片段按总时长均匀缩放，未严格对应独立设置的攻击时刻。现在按动作时钟分段映射至挥爪、双爪两次接触、砸地与吐息释放姿态；动画不改变真实接触伤害规则。

## 下一步按此顺序完成

1. **一个对局的操控基准**：只用先锋与现有怪兽调起停、转向、攻击输入、闪避、防御、受击恢复。重点测输入是否及时且可预测，不能单纯提高惯性或加硬直当重量感。记录输入到起手、接触时刻和可恢复控制时刻。
2. **角色与动画返工**：机甲需要踏步、髋肩传力、释放、命中随动、回收；怪兽需要低重心、非对称爪击、躯干扑压和可读的失衡动作。现有程序烘焙与人形骨架并未解决这些美术问题。若寻找替换资产，先验收轮廓、骨架、动画清单和许可，再接入。不能只换一张截图好看的静态网格。
3. **命中反馈统一**：按肉身/甲壳/装甲/混凝土区分局部反应、火星、碎片、粉尘和声音；拳、刀、喷射、吐息各自保留特征。先把受力方向、特效起点、音效起点与真实接触对齐，再增加层次。现有普通拳击仍复用通用火花/闪光，本轮未重做特效资产。
4. **一街区美术样板**：减少重复建筑、玩具行人和杂物带来的比例冲突；统一模型、贴图密度、日光阴影与空间尺度。压缩 HUD，确保角色动作优先可见。先优化战斗中的实际帧时间与加载，再考虑高开销后处理。
5. **真人试玩与体感验收**：新玩家能否看懂起手、主动躲开、判断是否打中、愿意重试；实测摄像头延迟、误触发、遮挡和疲劳。脚本驱动碰撞或合成姿态结果不能替代这些验收。
