# V18：能量炮动作链、怪兽动作加载和战斗遮挡

本轮仍未达到《Override 2》的发行品质。这里记录实际代码与浏览器验证，不以增加系统数量或测试通过数量代替体验验收。

## 已落实

- 能量炮使用共享的秒制时间定义：0.32 秒释放、0.6 秒散热、0.85 秒结束。角色片段、发射调度与表现标记共用定义。
- 动作从原先按正弦往前抬手改为：预先架炮、左臂支撑、右肩后坐、回稳、降低手臂。删除额外叠加的旧抬胸曲线，避免抵消新动作。
- 拳位上安装四片展开的金属导轨、导能内轨、收束电弧和短促定向喷流。几何与材质一次创建，顶点缓冲更新电弧；不逐帧创建发射装置。不再用原来的蓄力光团和炮口圆环叠加遮盖角色。
- 保留现有真实弹体飞行、楼体拦截、有限碰撞半径与接触伤害。没有改成按键即扣敌人血，也没有添加穿墙光束。
- 怪兽爪击的碰撞与拖尾共用出手侧和时间窗口。双爪片段实际固定左、右顺序，不能使用随机侧参数猜测第一爪；普通挥爪只显示对应侧。
- 修复加载顺序错误：旧 `v10_monster_*` 别名曾覆盖新制作的 `beast_idle/walk/run`。现在新动作优先；行走、奔跑保留原有低重心腿部轨迹，替换上身爪臂。待机爪位降低并稍微向外，不保持拳击抱架。
- 建筑遮挡从中心投影近似改为线段与实际建筑包围盒求交。分别检查角色脚部、躯干、头部，前景矮楼遮脚时也可渐隐；目标后面的天际线保持不变。

## 本轮证据

- `npm test`：62 项通过；新增能量炮前后时序、左右爪窗口、建筑角落/矮墙/相机在楼内/目标后方的遮挡测试。
- `npm run build`：通过，Rapier 大包警告仍在。
- `scripts/plasma-cycle-smoke.js`：浏览器中 0.283 秒无弹、0.35 秒一颗弹且喷流可见；装置与真实拳位误差小于 0.001 米；受击打断不发弹、重开无装置残留；检查运行与着色器错误。
- `scripts/monster-stance-smoke.js`：新动作没有被旧别名覆盖；步行/奔跑的原始腿部轨迹保留；待机及两个移动速度下，双爪均位于肩前、肩下。它是骨骼几何检查，不证明动画达到美术验收标准。
- `scripts/attack-timing-smoke.js`：重拳接续，以及两个阶段的挥爪/双爪/砸地/吐息触点时刻验证。
- `scripts/flight-combat-smoke.js` 与 `scripts/pacific-combat-smoke.js`：喷气、技能释放、连击、两次爪击、闪避、防御、受击、胜负与重开回归。
- 实看截图：`output/playwright/plasma-{brace,fire,vent,recover}-v18.png` 与 `monster-stance-v18.png`。

## 复评：离目标还差在哪里

1. **动作美术**：本轮修的是实际失效的动作加载与一条技能链，仍使用程序烘焙与现有骨架；没有获得专业怪兽表演、整套近战动作与受击动画。
2. **角色资产**：现有角色比例与装配受原始模型限制，三个机甲也不是三套独立的优质角色。新炮口装置不是角色整体重制。
3. **城市美术**：楼型与窗格重复、路面和小物件风格不一致。截图仍有明显程序生成感。建筑可破坏不等于达到了成熟游戏的场景制作水准。
4. **技能表现**：能量炮有了独立表现链，其他技能尤其怪兽砸地、终结技仍需要统一接触时刻、材质与镜头，避免大量圆环/通用爆炸。
5. **体验验收**：没有真人摄像头试玩，不能确认实际输入延迟、误识别、遮挡与疲劳；脚本合成输入不能替代真人体验。

下一批重点是一个街区和一组角色的完整质量样板，以及真人可检验的体感战斗流程。未完成这些，不应称为正式版，也不应承诺已接近竞品。
