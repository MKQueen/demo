# 角色与移动升级 v10

2026-10-23。本轮落实升级路线中的角色基准与移动部分，并修正新姿态暴露出的攻击问题。仍是向完整游戏推进中的版本，不将此次改动等同于整个正式版路线完成。

## 已接入游戏

- 机甲：普通待机、战斗待机、格挡独立；降低骨盆、加宽错脚站位，待机不再持续使用格挡动作。
- 怪兽：低重心、前探头颈、下垂前爪、宽脚支撑；行走/奔跑使用重新制作的全身动作，替换下载资源的人形腿部步态。
- Blender 制作 12 段动画，导出骨骼旋转和位置轨道；保留 `.blend` 源工程和可重建脚本。使用现有下载模型，没有新增独立机甲或怪兽模型。
- 动画步速匹配实际位移；侧移和后退使用更短步幅与相应步频。支撑期世界坐标固定脚掌，使用两段腿部 IK 保留脚掌朝向。
- 走跑切换保留步态相位，移动过渡延长至 0.23 秒。原地转向使用迈步动画与上身朝向平滑。尚未制作独立的启动/刹车专用片段。
- 基础步行/奔跑从 13/27 调整为 10/22，喷气机动保留。实际关卡节奏仍需人工试玩调优。
- 攻击以新全身姿态为基准，修复低姿态下沿用旧肩部坐标导致爪击反折的问题。近战突进在承诺后保持方向，修正侧闪后拳头继续追踪目标的问题。
- 修正操作说明中残留的远程刀波描述：光刃按实体接触命中。

## 验收证据

引擎内固定正面/侧面检查关闭了 HUD、战斗特效与城市遮挡。预览为手动推进动画和位移的角色验收，不能作为正常战斗、平衡或性能测试的证据。

- `docs/screenshots/character-v10.gif`：待机、前进、侧移、停步、转身。
- `output/playwright/character-v10-front.png`、`character-v10-profile.png`：正面与侧面。
- 怪兽待机骨盆高度约 8.89，头部在骨盆前约 3.49，双脚横向间隔约 6.39，手爪低于骨盆约 1.47（游戏单位，静态骨骼测量）。用于说明姿态实际改变，不作为美术质量评分。
- 30/60/120 Hz 下，0→10→22→0 速度切换与前进/侧移/后退的支撑脚误差最大约 0.134 游戏单位；这是脚骨相对锚点误差，不等同于所有脚底顶点无穿透。
- 怪兽待机、走跑、爪击、双爪、砸地、吐息、咆哮全周期检查中，手腕保持在肘部前方；该检查用于防止已知反折回归，不能替代完整关节审查。
- 接触战斗、不同帧率命中、刀斩取消、双方完整战斗、喷气、改装配置、胜负重开及资源释放的浏览器回归通过；15 项单元测试与生产构建通过。

主要脚本：`character-v10-smoke.js`、`character-speed-smoke.js`、`release-v7-smoke.js`、`contact-combat-smoke.js`、`contact-motion-smoke.js`、`contact-cancel-smoke.js`、`pacific-combat-smoke.js`、`flight-combat-smoke.js`、`browser-smoke.js`。

## 重建动作

```sh
/Applications/Blender.app/Contents/MacOS/Blender --factory-startup -b --python scripts/animation/build_character_library.py
```

运行资产位于 `public/models/pacific/*Motion.glb`。源工程位于 `assets/animation/`，动作时长与步幅记录在 `clip-metadata.json`。
