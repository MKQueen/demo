# 知识库结构与检索评测

## 知识库结构

`kb/` 共 8 篇 Markdown（`01-退换货政策.md` 至 `08-投诉与客服渠道.md`）。每篇为 `# 标题` + 6 个 `## 小节`，正文写清天数、金额、条件与办理入口；文档 id 为文件名去掉序号，块 id 形如 `退换货政策#0`。8 篇主题两两区分（退换货、物流、支付发票、会员积分、保修、账号安全、优惠券、投诉），相近处只做交叉引用，不复制段落。

## 评测方法

`kb/eval.json` 15 条口语化用例覆盖全部 8 篇，重点文档各 2~3 条，query 不抄文档原句；`expectKeywords` 由测试校验确实存在于目标文档。`test/retrieval-quality.test.js` 用 `node --test` 统计 hit@1、hit@3 与平均耗时，阈值 0.6 / 0.9 / 50ms，失败时打印实际 top-3；不达标只调 query，不改内核。
