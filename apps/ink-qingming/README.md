# 水墨清明上河图 · 东京城长卷

用 Three.js 程序化「画」出张择端《清明上河图》并一路扩成整座东京城的长卷：
郊野 → 汴河 → 虹桥 → 城门 → 街市 → 州桥 → 御街 → 大内，一卷拖过去，北宋汴京的烟火气就在绢上慢慢展开。

## 怎么看

- **拖动 / 滚轮 / ← →**：展卷（相机沿画卷横向推进）
- **底部卷尺**：点八段朱印「郊野 / 河市 / 桥市 / 城门 / 街市 / 州桥 / 御街 / 大内」直接跳到那一段
- **停卷 / 续卷**：自动展卷开关
- **藏签**：隐藏绢面上的段落朱印
- **墨色**：调节水墨浓淡

八段各有一张纸卡，写着这一段的注脚。

## 画面里有什么

- **郊野**：疏林薄雾、农田田垄、5 间茅草农舍（土墙/篱笆/水井/柴垛/鸡窝/半塌土墙）、
  扫墓归来的队伍（人 + 轿 + 马）、驮炭驴队、小桥水沟、坟茔与白纸幡。
- **汴河**：沿河心生成的宽水面（两层线描水纹缓慢流动）、6 条船——漕船、客船、乌篷小舟，
  以及一条 26 米大货船从桥下过（桅杆先放倒一半、进桥洞压低）、北岸木栈桥/货堆/苇席棚、
  拉纤的纤夫、码头茶棚。
- **虹桥**：无柱木拱桥（叠梁拱肋 + 横梁 + 桥板，露明拱架），桥面 4 个小摊、60 个行人，
  桥头高杆朱幡。
- **城门**：9 米城墙 + 马面/垛口 + 重檐城门楼（拱形门洞、排叉柱、朱漆门、石狮、告示牌），
  门外的关厢茶摊、脚店。
- **街市**：35 间铺面（酒楼彩楼欢门、茶坊大伞、香药铺冲天招牌、脚店、算命摊、饼摊），
  幌子/望子/横匾/灯笼，车辙与排水沟，货担、酒瓮、拴马桩、马驴板车，200+ 行人挑夫轿马。

**州桥 / 御街 / 大内**：御街跨汴河的州桥、桥两岸河市、御廊铺席与行道树；相国寺山门/大殿/资圣阁/塔；
樊楼三层重檐与彩楼欢门；大内朱红宫墙、宣德门与门内大庆殿。

全场景是 100% 程序化：没有一个外部模型/贴图，树用 `lib/flora.js` 的程序化墨树，
屋顶用 `lib/roof.js` 的中国屋顶生成器，水面/人物各是一套自写 shader。

## 技术

- **长卷相机**：只有「展卷进度」是主自由度，五段各有镜头预设（远近/俯仰/偏角），
  相邻两段之间平滑插值，像有人拿着画慢慢移动。
- **水墨后期**（`src/lib/ink.js`）：深度 + 亮度 Sobel 墨线 → 墨─绢双色调分级 → 绢纹/压角，
  远景色淡、近景墨重。
- **人物**（`src/world/people.js`）：一张手绘「人物谱」Canvas 贴图 + InstancedMesh 广告牌，
  12 种人物（挑夫/轿子/骑马/骆驼/驴/船工/摊贩/书生/僧人/孩童/妇人…），
  行走/摇晃在顶点着色器里完成，全部人一次 draw call。
- **长卷坐标真源**：`src/layout.js`（1 世界单位 = 1 米；河心线/桥/城墙/街市/五段坐标都在这里）。

## 目录

```
src/
├─ layout.js          长卷坐标真源（五段、河道、虹桥、城门、街市、镜头预设）
├─ camera-scroll.js   展卷相机（拖动/滚轮/卷尺/自动展卷）
├─ main.js            组装、后期、循环
├─ ui.js / labels.js  卷尺、题跋、纸卡、段落朱印
├─ people.js?         → 在 world/people.js
├─ world/
│  ├─ index.js        拼装
│  ├─ terrain.js      绢底、河岸、土路
│  ├─ river.js        汴河水面/船/码头/纤夫
│  ├─ bridge.js       虹桥与桥市
│  ├─ town.js         城墙/城门楼/街市
│  ├─ country.js      郊野
│  ├─ backdrop.js     远岸/城影/雾带
│  └─ people.js       人物与走兽（InstancedMesh）
└─ lib/               水墨后期、屋顶、树、纹理、材质、随机数
```

## 性能

广角全场景约 **9.1 万三角形 / 99 draw calls**（树运行时另有 flora 批次），M 系列芯片实测 **120fps**（PixelRatio 1.85）。
