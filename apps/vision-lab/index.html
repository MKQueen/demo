OPERATING NOTES

怎么玩这个 Demo

  1. 选输入：摄像头实时流、上传视频文件，或上传图片（也可以用两张示例图快速体验）。
  2. 看标注：检测框颜色对应类别；右侧列表按置信度排序，点击条目可以高亮对应目标。
  3. 调参数：置信度阈值越高越严格；帧率受设备性能影响，CPU 推理通常 8–15 FPS。
  4. AI 解读（可选）：本地运行 npm run serve 并配置模型 Key 后可用；只把识别标签发给模型，不上传画面。静态部署时该功能会显示未连接。

模型：MediaPipe EfficientDet-Lite0（COCO 80 类），WASM + Worker 本地推理；摄像头画面不会离开你的电脑。 示例图片来自 Pexels（Pexels License，免费使用）。
