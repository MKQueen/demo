      HOW IT'S BUILT / 关于

      一个仓库，
      七个可独立开发的 Demo。

      这不是七个静态截图拼成的页面。每个作品都是一个可单独开发、单独构建的前端工程， 由构建脚本统一拼装成一个纯静态站点 —— 可以直接上传到任意静态托管； 需要真实模型的两个 Demo，由本地 npm run serve 提供模型转发与 Agent 后端。

      1. 01

        独立开发

        每个 Demo 有自己的源码、依赖与构建配置，互不干扰。

      2. 02

        统一拼装

        一条命令构建全部作品，注入返回入口，输出可直接部署的 site/ 目录。

      3. 03

        本地真实运行

        七个 Demo 的构建产物都是相对路径静态资源，任意子目录托管；VISION LAB 的物体识别完全在浏览器内完成，RAG 观测台的真实模型回答经同源 /api/llm 极薄转发，mini-opencode 由 npm run serve 拉起本机 Node 后端、经同源 /api 代理真实执行模型与工具。
